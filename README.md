# Badges

All badges have a height of 20 pixels. It is recommended to use the following
CSS rule:

```
img.badge {
  image-orientation: from-image;
  vertical-align: middle;
  image-rendering: pixelated;
  width: auto;
  height: 19px;
  min-height: 19px;
  max-height: 19px;
}
```

## Contributing

This collection is a bit odd, with two main categories:

- Pixelated versions of common badges ("source on GitHub")
- Slightly humorous/sarcastic vanity badges ("Cargo Cultist", "Move Zig", "Featured on N-Gate")

I'm not too likely to accept something from the first category, because I tend
to only add things that I use personally. I'm not likely to accept something
from the second category either, unless I find it funny. Still, I'd encourage
PRs — in the worst case you still have a fun badge that you can use.

All badges should be PNG (indexed) or GIF.

Sizing is another problem. I'm not too happy with my choice of `20px`-high
badges; if I had started this today I would've chosen `88x31`. Newer badges will
probably be in this size, but I'm not going to convert existing badges.
